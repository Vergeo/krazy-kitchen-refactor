Krazy Kitchen merupakan sebuah program yang dibentuk untuk mensimulasikan keadaan sibuk di sebuah restoran. Tujuan dari program ini adalah mengelola pesanan secara efisien, mengurus inventaris, dan memastikan pelanggan menerima pesanannya tepat waktu. Setiap pesanan mempunyai batas waktu sehingga pemain harus menyelesaikan pesanan secepatnya sebelum pelanggan marah. Pemain juga harus memastikan stok bahan makanan cukup untuk menyiapkan pesanan dan menambah stok jika tidak diperlukan.

Program ini terpisah menjadi 2 mode, yaitu mode output dan mode input sehingga program harus dijalankan pada 2 jendela yang berbeda. Pada mode output, pemain dapat melihat keadaan restoran saat ini, termasuk pesanan dan stok. Pada mode input, pemain dapat berinteraksi dengan program untuk mengelola operasi restoran. Untuk menjalankan program ini, direkomendasikan untuk mengubah proyek menjadi file tipe jar dengan menggunakan IDE Eclipse.
